## email_pro

**作者:** dq
**版本:** 0.0.1
**类型:** 工具

### 简介

一个 Dify 插件，提供通过 SMTP/IMAP 协议检索和发送邮件的邮件工具。包含两个工具：

- **发送邮件**：通过可配置的 SMTP 服务器发送邮件，支持 TLS、SSL 和无加密模式。
- **检索邮件**：通过 IMAP 协议从配置的邮箱中检索邮件，支持按发件人、主题关键词、日期范围和邮件文件夹筛选。

### 配置

1. 在 Dify 中安装本插件。
2. 在插件设置中配置以下凭证：
   - **SMTP 服务器地址**：你的 SMTP 主机（如 `smtp.gmail.com`）
   - **SMTP 端口**：你的 SMTP 端口（TLS 常用 `587`，SSL 常用 `465`）
   - **邮箱地址**：用于认证的邮箱地址
   - **邮箱密码 / 应用专用密码**：邮箱密码或应用专用密码
   - **加密方式**：选择 START TLS、SSL 或无加密

> Gmail 用户需要生成[应用专用密码](https://support.google.com/accounts/answer/185833)。
> QQ 邮箱用户请使用授权码而非登录密码。

### 工具

#### 发送邮件
向指定收件人发送邮件，需填写收件人邮箱、主题和正文内容。返回结构化输出，包括状态、发件人、收件人、主题和时间戳。

#### 检索邮件
按文件夹、发件人、主题关键词和日期范围检索邮件。返回匹配的邮件详细信息，包括邮件正文。

### 使用方法

配置完成后，可在 Dify 工作流中使用：

1. **发送邮件**：填写收件人邮箱、邮件主题和正文内容。
2. **检索邮件**：可选按文件夹（默认 INBOX）、发件人地址、主题关键词、时间范围（最近 N 天）和最大结果数筛选。
